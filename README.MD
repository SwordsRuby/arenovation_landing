# Arenovation - Сайт ремонтной компании

![Arenovation Logo](assets/img/logo/logo.png)

## 📋 О проекте

**Arenovation** - это современный одностраничный сайт для компании, предоставляющей услуги по ремонту и дизайну интерьеров. Проект разработан с акцентом на визуальную привлекательность, удобство использования и адаптивность под различные устройства.

Сайт представляет собой визитку компании, демонстрирующую спектр услуг, портфолио работ и отзывы клиентов. Дизайн выполнен в современном стиле с использованием градиентных элементов и анимированных переходов.

## ✨ Основные функции

- **Адаптивный дизайн** - корректное отображение на всех устройствах
- **Бургер-меню** - удобная навигация на мобильных устройствах
- **Аккордеон** - раскрывающийся список услуг
- **Слайдер** - автоматическое перелистывание портфолио
- **Табы** - переключение отзывов клиентов
- **Модальные окна** - форма обратной связи
- **Валидация форм** - проверка введенных данных
- **Плавные анимации** - улучшенный пользовательский опыт

## 🛠️ Технологии

- **HTML5** - семантическая разметка
- **CSS3** - кастомные стили, анимации, Flexbox
- **JavaScript (Vanilla)** - интерактивность без внешних библиотек
- **Google Fonts** - шрифты Roboto и Marck Script
- **Font Awesome** - иконки (через Unicode)

## 🎨 Особенности дизайна

### Цветовая схема
- **Основной акцент**: изумрудный (#19ceb6)
- **Фон**: полупрозрачный с эффектом стекла (glassmorphism)
- **Текст**: белый для высокой контрастности
- **Градиенты**: изумрудный градиент для кнопок

### UI/UX решения
- **Glassmorphism** - эффект размытого стекла на карточках
- **Плавные переходы** - анимации при наведении и переключении
- **Интерактивные элементы** - визуальная обратная связь

## 📱 Адаптивность

Сайт оптимизирован для трех брейкпоинтов:
- **Десктоп**: > 1210px
- **Планшет**: 810px - 1210px
- **Мобильные**: < 810px

На мобильных устройствах:
- Бургер-меню заменяет навигацию
- Уменьшаются размеры шрифтов и отступов
- Табы превращаются в вертикальный список
- Слайдер адаптируется под размер экрана
